# 🍕 Pizza Sales Analytics Dashboard

An interactive dashboard built using **HTML, CSS, and JavaScript** to analyze pizza sales performance, revenue trends, product performance, and customer ordering patterns.

## 📊 Project Overview

This project focuses on analyzing pizza sales data through an interactive dashboard. It presents key business metrics and visual insights to help understand sales performance, identify popular products, and explore ordering trends.

## 🎯 Project Objectives

- Analyze total revenue and order performance.
- Identify the best-selling pizzas.
- Compare sales across pizza categories and sizes.
- Understand monthly sales trends.
- Analyze customer ordering patterns by day and hour.
- Present business insights through interactive visualizations.

## ✨ Dashboard Features

- **KPI Cards:** Total Revenue, Total Orders, Pizzas Sold, and Average Order Value.
- **Monthly Revenue Trend:** Track revenue performance over time.
- **Category Analysis:** Compare revenue across pizza categories.
- **Top 10 Pizzas:** Identify the highest-revenue pizza products.
- **Size Analysis:** Understand sales distribution by pizza size.
- **Ordering Patterns:** Explore orders by weekday and hour.
- **Interactive Filters:** Filter data by date, category, size, and pizza name.
- **Detailed Sales Table:** Explore product-level sales information.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Data Analysis
- Data Visualization

## 📈 Key Business Questions

1. What is the total revenue generated?
2. Which pizzas generate the highest revenue?
3. Which pizza category performs best?
4. Which pizza size contributes most to sales?
5. How does revenue change month by month?
6. Which days and hours have the highest order activity?

## 💡 Business Value

The dashboard helps transform raw sales data into meaningful insights. It supports better understanding of product performance, sales trends, and customer ordering behavior, which can help businesses make data-driven decisions.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML dashboard file in your web browser.
4. Explore the dashboard using the interactive filters.

No additional installation is required.
